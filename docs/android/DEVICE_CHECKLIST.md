# Towerbound 真機 checklist(Android)

呢一輪冇 adb 裝置亦都冇 emulator,所以「notification 有冇真係派落嚟」、
「觸控準唔準」、「熱唔熱」呢啲**只有真機答得到**嘅問題留返喺呢度。
邏輯本身(收到 notification 之後做啲乜)已經有 `test/MobileTest.gd` 守住 ——
呢張紙唔重複嗰半,淨係問部機。

**裝邊個檔:`dist\Towerbound-1.0.0.apk`**(唔係 .aab —— .aab 淨係俾 Play
Console 食,部機裝唔到)。

---

## 0. 安裝

1. 用 USB / 雲端將 `Towerbound-1.0.0.apk` 傳落部機。
2. 開檔案管理員撳個 apk。第一次會問「允許由呢個來源安裝」→ 允許。
3. Play Protect 可能會彈「未知開發者」→ 揀「仍然安裝」。
   (呢個係 sideload 嘅正常提示,上咗 Play 之後唔會再有。)

- [ ] 裝到,冇報「套件解析錯誤」
- [ ] Launcher 上面個 icon 係**箭塔**,唔係 Godot 個機械人,亦唔係一個灰色方格
- [ ] 個名顯示 **Towerbound**(唔係「塔防要塞」,亦唔係 `godot-project-name`)
- [ ] 長撳 icon → 如果部機支援 themed icon(Android 13+,開咗「主題圖示」),
      單色版都認得出係座塔

---

## 1. 開場

- [ ] 開場畫面係**暖深色底 + 箭塔**,冇一閃灰色(嗰個灰色 = boot splash 設定甩咗)
- [ ] 開場冇彈任何權限請求。**一個都唔應該有。**
- [ ] 入到主選單,中文字**全部**顯示到,冇一格格嘅豆腐方塊
      (英文介面都要行一次:設定 → 語言 → English)
- [ ] 畫面係直版,冇上下黑邊過闊 / 左右爆界
- [ ] 狀態列同導航列冇遮住任何掣(immersive mode)

## 2. 直版鎖定

- [ ] 打橫攞部機 → 畫面**唔會**轉橫
- [ ] 倒轉攞部機(180°)→ 畫面會跟住轉(sensor portrait 就係咁)

## 3. 觸控

- [ ] 主選單每粒掣撳得到,冇「撳咗冇反應」
- [ ] 選關畫面上下掃 → 有慣性,唔會黐手指
- [ ] 圖鑑左右掃 → 揭得到頁
- [ ] 戰鬥入面:由下面塔卡**拖**去地圖 → 個幽靈跟得住手指,放手就起到塔
- [ ] 兩隻手指縮放地圖(如果有)/ 單指拖動地圖

## 4. 返回鍵 / 返回手勢 ★

呢一項係呢一輪改動最集中嘅地方,逐格試:

- [ ] **主選單**撳返回 → 彈「再撳一次返回離開遊戲」,**唔會**即刻退出
- [ ] 兩秒之內再撳一次 → 退出 app
- [ ] 等多過三秒之後先再撳 → **唔會**退出,係再彈一次提示
- [ ] **選關 / 商店 / 升級 / 設定 / 圖鑑**撳返回 → 退返主選單
- [ ] **戰鬥中**撳返回 → 彈暫停選單,戰鬥停低。**唔會**離開戰鬥,更加唔會退出 app
- [ ] 暫停選單開住再撳返回 → 收返暫停選單,繼續打
- [ ] 暫停 → 開圖鑑 → 撳返回 → 退返**暫停選單**(唔係彈返主選單,唔係退出戰鬥)
- [ ] 用**手勢**(由螢幕邊掃入)重複一次上面每一格,行為要一模一樣

## 5. 切去背景 ★

- [ ] 戰鬥打到一半撳 Home → 返 launcher
- [ ] 喺 launcher 度停 10 秒:**聽唔到任何遊戲聲**
- [ ] 由最近應用清單返返去 → 停喺**暫停畫面**,怪物冇郁過,血量同開頭一樣
      (最重要嗰項:唔可以一返嚟就發現輸咗)
- [ ] 撳「繼續」→ 打得返落去
- [ ] 喺**設定**入面撳咗靜音 → 切走 → 切返 → **仍然係靜音**(唔准幫你開返聲)
- [ ] 選單畫面(唔係戰鬥)切走再切返 → 畫面照郁,唔會凍住
- [ ] 打緊機嗰陣有電話打入 → 遊戲停低 + 收聲;收線返返去 → 停喺暫停畫面

## 6. 存檔 ★

- [ ] 打贏一關 → 睇住魔晶數量
- [ ] 由最近應用清單**掃走**個 app(唔係撳返回)
- [ ] 重新開 app → 魔晶、通關進度、已買嘅塔/升級**全部**仲喺度
- [ ] 開場**冇**彈「上一次啟動非正常結束」嘅閃退報告
      ★★ 呢一項失敗 = `Mobile._on_paused()` 嗰句 `Crash.disarm()` 冇行到,
      要報返;佢會令每一個正常收工嘅玩家下次開場都見到一版假閃退。
- [ ] 設定入面改咗語言 / 音量 / 省電模式 → 殺 app 重開,設定仲喺度

## 7. 效能同發熱

- [ ] 連續打 **最少 3 關**(建議第 1、第 5、第 10 關)
- [ ] 再打**一場合約關**(選關畫面有合約標記嗰啲)
- [ ] 全程順唔順?有冇一卡一卡?(尤其係 boss 出場、放大招嗰陣)
- [ ] 打完 3-4 關之後,部機背面燙唔燙?同你之前玩網頁版
      (<https://jackncw.github.io/game-towerdefence/>)打同樣關數比較 ——
      **native 應該冇咁熱**。如果反而更熱,要報返。
- [ ] 設定 → 開「省電模式」→ 再打一關:應該仲係順,而且再涼啲

## 8. 權限(Play 嘅 Data safety 表格靠呢一項)

- [ ] 設定 → 應用程式 → Towerbound → 權限:應該係
      **「未授予任何權限」**,連「未使用嘅權限」清單都應該係空
- [ ] 開飛行模式 → 整個 checklist 由頭行一次:**全部行為要一模一樣**
      (呢個係「離線單機」最直接嘅證明)

## 出咗問題點報

`user://logs/` 入面有兩份證物:引擎 log(`godot.log`,有完整 stack trace)同
遊戲麵包屑(`crash.log`)。Android 上面 `user://` 嘅實際位置係

```
/Android/data/com.jatgaming.towerbound/files/logs/
```

用檔案管理員入到去,將兩個檔傳返出嚟就得。冇 root 都攞得到。

如果部機接得到電腦,`adb logcat -s godot` 睇得到即時輸出。
