私隱政策(繁體中文)

Towerbound(以下稱「本遊戲」)係一款離線單機遊戲。 本遊戲唔會收集、儲存或者傳輸任何個人資料。

我哋收集啲乜?

冇。本遊戲唔會向開發者或者任何第三方傳送任何資料。具體嚟講:

  • 唔會收集姓名、電郵、電話、地址或者任何可以識別你身分嘅資料。
  • 唔會收集裝置識別碼(廣告 ID、IMEI、MAC 位址等)。
  • 唔會收集位置資訊。
  • 唔會收集通訊錄、相片、檔案、麥克風或者相機內容。
  • 唔會收集使用行為分析、崩潰報告或者任何遙測資料。

權限

本遊戲唔要求任何 Android 權限,連 INTERNET 都冇。 即係話,就算想傳資料出去,喺技術上都做唔到 —— 個 app 根本冇網絡權限。

廣告同第三方

  • 冇廣告。
  • 冇第三方 SDK(冇分析工具、冇廣告網絡、冇社交登入、冇崩潰回報服務)。
  • 冇應用程式內購買。
  • 冇帳戶、冇登入、冇雲端同步。

你嘅遊戲進度

你嘅存檔(關卡進度、魔晶、已解鎖嘅塔同升級、遊戲設定)淨係儲存喺你部裝置本機, 放喺本遊戲自己嘅私人儲存空間入面。呢啲資料唔會離開你部機。

解除安裝本遊戲會一併刪除呢啲資料。除咗解除安裝之外,你唔需要向我哋提出任何「刪除資料」要求, 因為我哋一開始就冇你嘅資料。

兒童

本遊戲適合所有年齡層。由於本遊戲完全唔收集資料,亦都唔會收集兒童嘅個人資料。

網頁版

本遊戲亦都有一個喺 GitHub Pages 上面嘅網頁版。網頁版嘅存檔用瀏覽器本機儲存 (IndexedDB),同樣淨係留喺你部機。GitHub Pages 作為靜態網站寄存服務,可能會按照 GitHub 自己嘅私隱政策 記錄一般嘅伺服器存取記錄;呢個係寄存平台嘅行為,唔係本遊戲收集嘅資料。 Android 版完全冇呢一層 —— 佢唔連網。

政策變更

如果本政策有變,我哋會更新呢一頁同埋上面嘅「最後更新」日期。

聯絡

有任何關於私隱嘅問題,請電郵: jatgaming.info@gmail.com

Privacy Policy (English)

Towerbound (“the Game”) is an offline, single-player game. The Game does not collect, store, or transmit any personal data.

What we collect

Nothing. The Game sends no data to the developer or to any third party. Specifically, it does not collect:

  • Name, email address, phone number, postal address, or any other personally identifying information.
  • Device identifiers (advertising ID, IMEI, MAC address, and the like).
  • Location data.
  • Contacts, photos, files, microphone, or camera content.
  • Usage analytics, crash reports, or any other telemetry.

Permissions

The Game requests no Android permissions at all, not even INTERNET. It is therefore technically incapable of sending anything anywhere: the app has no network access.

Advertising and third parties

  • No advertising.
  • No third-party SDKs — no analytics, no ad networks, no social sign-in, no crash-reporting services.
  • No in-app purchases.
  • No accounts, no sign-in, no cloud sync.

Your game progress

Your save data (level progress, crystals, unlocked towers and upgrades, and settings) is stored only in local storage on your own device, inside the Game's private app storage. It never leaves your device.

Uninstalling the Game deletes that data. Beyond uninstalling, there is no data-deletion request to make of us, because we never had any of your data in the first place.

Children

The Game is suitable for all ages. Because it collects no data at all, it collects no personal data from children.

Web version

A browser version of the Game is also published on GitHub Pages. It stores saves in browser-local storage (IndexedDB), which likewise stays on your device. As a static-site host, GitHub Pages may keep ordinary server access logs under GitHub's own privacy statement; that is hosting-platform behaviour, not data collected by the Game. The Android build has no such layer — it does not go online.

Changes to this policy

If this policy changes, we will update this page and the “last updated” date above.

Contact

For any privacy question, email jatgaming.info@gmail.com
