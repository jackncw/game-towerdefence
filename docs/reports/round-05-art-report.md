## 5. 今輪碰到嘅工具/引擎伏位(留畀下輪)

1. `preload(x.gd).get_script_constant_map()` 係 **parse error**(「非靜態函式」),
   要 runtime `load()` 攞返個 GDScript instance 先叫得。
2. `art_export.gd` 入面 `_gallery_ui_kit()` 漏咗 `await` → 佢同下一個 gallery 並行行,
   影出嚟嘅圖係下一個 scene。**coroutine 一定要 await**。
3. Battle 打贏會 `Flow.goto` 換 root scene,任何 harness node 都會即刻被 free —
   要喺 `battle.ended` 一 set 就收工。
4. `var x := untyped.method()` 型別推斷失敗(今輪中咗 `monsters_in_radius`)—— 老問題。
5. 新增 `tools/asset_sheet.py`:純 Pillow 拼圖(towers / env / compare / --silhouette),
   改完 `gen_art.py` 即刻睇到,唔使等 4 分鐘嘅 Godot export。剪影模式對「剪影分唔分得開」
   呢類判斷特別有用。
